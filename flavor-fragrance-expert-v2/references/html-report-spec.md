# HTML 可视化报告规范 (HTML Report Specification)

> 本规范定义调香专家的 HTML 报告输出格式。
> HTML 报告在两个 MD 文档（极致还原版 + 合规落地版）之外额外输出，**可视化展示配方生成的完整过程**，而不仅仅是结果呈现。

---

## 一、设计目标

1. **过程可视化**：展示从需求到配方的完整推导过程，让用户理解"为什么这么设计"
2. **结果可视化**：用富视觉元素（色块、条形图、参数卡片、标签）呈现最终配方
3. **记忆透明化**：展示本次配方调用了哪些历史知识、沉淀了哪些新知识
4. **专业美观**：暖色调咖啡棕系、分章节卡片、信息密度高、视觉层次分明

---

## 二、报告结构（9 大章节）

HTML 报告包含以下章节，按顺序呈现：

### 第一章：报告头部
- 渐变色头部背景（深棕→咖啡棕→浅棕渐变）+ 右上角圆形装饰
- 配方名称（中英文，含图标 emoji）
- 副标题：从需求解析到配方落地的完整过程
- meta-tags 胶囊标签：日期、场景、香型、交互序号、版本说明

### 第二章：需求分析与记忆调用
- 需求解析表（目标场景、香型、关键诉求、输入信息、输出版本、合规标准）
- 用户偏好摘要 info-box（来自记忆库 PROFILE.md）
- 历史知识调用 info-box + 知识卡片网格（k-card）
  - 每张卡片含：知识编号(k-id)、标题(k-title)、描述(k-desc，含 `[K0XX]` 角标)、来源(k-source)
  - 首次交互时显示建库提示

### 第三章：配方设计过程（核心可视化章节）
展示配方从无到有的推导过程：
- **3.1 特征指纹选择决策**：SVG 决策树（svg-container 内嵌 SVG）
  - 根节点（深棕渐变矩形）→ 判断节点（浅棕色块）→ 分支（入选=绿底/落选=橙虚线底）→ 结论节点
  - 每个选择节点说明"为什么选这个、为什么不选那个"
- **3.2 香韵分路推导过程**：四步流程图卡片（flow-steps + flow-step）
  - 横向排列，步骤间用 `→` 箭头连接
  - 每步含编号圆圈(step-num)、标题(step-title)、描述(step-desc)
  - 分路数量自适应说明 info-box
- **3.3 挥发梯度设计**：彩色色块条（gradient-bar + gradient-segment）+ 明细表
  - 头香（橙色渐变）/ 体香（棕色渐变）/ 基香（深棕渐变）
  - 每段宽度按占比 flex 分配
- **3.4 关键用量决策（OT值导向）**：表格 + 警告 info-box
  - 组分、OT值、用量、感官贡献逻辑（含 `[K0XX]` 角标）

### 第四章：极致还原版配方
- 完整配方表（序号、组分、CAS、类别、用量、功能层、OT值、合规状态）
- 彩色合规状态标签（tag-ok 绿/tag-warn 橙/tag-ban 红）
- 禁用组分行使用红色背景（`style="background:#FFEBEE;"`）
- 配方总计说明

### 第五章：香韵结构分析
- **五层骨架拆解表**：骨架层、角色、关键组分
- **香韵分路贡献度可视化**：水平条形图（bar-chart + bar-row + bar-fill）
  - 每行：分路标签(bar-label) + 渐变填充条(bar-fill，标注占比和定位)
- **关键洞察 info-box**：含 `[K0XX]` 角标
- **特征指纹组分详解表**：特征指纹、角色、OT值、用量、感官功能

### 第六章：风格参数评估
- 参数卡片网格（param-grid + param-card），每个卡片含：
  - 标签(p-label)、数值(p-value)、进度条(p-bar + p-fill)
- 参数实现方式表（参数、目标值、实现方式，含 `[K0XX]` 角标）

### 第七章：合规落地版配方
- 双版本差异说明表（diff-table）：
  - 对比维度、极致还原版(col-extreme 黄底)、合规落地版(col-compliant 绿底)、差异说明
- 合规版完整配方表（序号、组分、CAS、用量、功能层、合规状态、与极致版差异）
  - 新增/替代组分行使用绿色背景（`style="background:#E8F5E9;"`）
  - 差异列用颜色标注（降量=橙色 `#E65100`、增量=绿色 `#2E7D32`）

### 第八章：合规审查报告
- 适用标准说明
- 受限组分处理清单表（原组分、CAS、限值要求、极致版用量、合规版处理、替代方案）
  - 替代方案列含感官说明小字
- 合规结论 success info-box（含 `[K0XX]` 角标）

### 第九章：雾化工程化适配（电子雾化场景）
- **溶解度校验表**：组分、PG/VG溶解度、风险等级(risk-low/mid/high)、操作建议
- **热稳定性评估表**：组分、分解温度、雾化风险、产物风险、建议
- **积碳风险评级**：水平条形图（bar-chart），每行标注组分名和用量
  - 风险色：高=红 `#F44336`、中=橙 `#FF9800`、低=绿 `#4CAF50`
- **体感优化建议表**：体感维度、评估、建议（含 `[K0XX]` 角标）
- **量产风险提示**：warning info-box（含 `[K0XX]` 角标）
- 非雾化场景则省略本章并注明

### 第十章：使用建议与知识沉淀
- 最终推荐配方 success info-box（含 `[K0XX]` 角标）
- 工艺建议表（工艺环节、建议，含 `[K0XX]` 角标）
- 质控建议表（检测项、方法、标准）
- 本次沉淀的新知识卡片网格（k-card）
- 记忆库更新说明 info-box

## 三、视觉设计规范

### 3.1 配色方案（暖色调·咖啡棕系）

| 色值 | 用途 |
|------|------|
| `#F5F0EB` | 页面背景：暖米色 |
| `#FFFFFF` | 卡片背景：纯白 |
| `#EDE4DA` | 卡片边框：浅暖灰 |
| `#3E2723` | 主文字：深棕 |
| `#5D4037` | 次要文字：中棕 |
| `#6F4E37` | 主色调：咖啡棕（标题、图标） |
| `#8B6F47` | 辅色调：浅咖啡 |
| `#D4A574` | 强调色：焦糖金（边框、装饰） |
| `#E8F5E9` / `#2E7D32` | 合规通过：浅绿底 + 深绿字 |
| `#FFF3E0` / `#E65100` | 需评估：浅橙底 + 深橙字 |
| `#FFEBEE` / `#C62828` | 禁用：浅红底 + 深红字 |
| `#F5EDE3` | 表头背景：浅米色 |
| `#FAF6F1` | hover 行背景 |

**头部渐变**：`linear-gradient(135deg, #3E2723 0%, #6F4E37 50%, #8B6F47 100%)`

### 3.2 字体

```css
font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC', 'Microsoft YaHei', sans-serif;
```
正文 14px，表格 13px，标签 11px。

### 3.3 核心组件

#### 章节卡片（section）
- 白色背景，圆角 14px，1px 浅暖灰边框（`#EDE4DA`）
- 阴影：`0 2px 12px rgba(62,39,35,0.06)`
- 内边距 28px 30px，章节间距 20px

#### 章节标题（section-title）
- 20px 加粗深棕色，底部 2px 分隔线
- 前缀数字图标：32×32px 圆角方块，咖啡棕渐变背景，白色数字

#### 子标题（subsection-title）
- 16px 加粗咖啡棕色
- 左侧 4px 焦糖金竖线装饰（`#D4A574`）

#### 表格（table）
- 全宽，边框合并，13px 字号
- 表头：浅米色背景（`#F5EDE3`），深棕字，底部 2px 焦糖金线
- 单元格：8px 内边距，底部 1px 浅灰线
- 行 hover：浅暖白背景（`#FAF6F1`）

#### 合规标签（tag）
- 圆角 4px，11px 字号，加粗
- `tag-ok`：浅绿底 + 深绿字
- `tag-warn`：浅橙底 + 深橙字
- `tag-ban`：浅红底 + 深红字

#### 知识卡片（k-card）
- 网格布局，最小 300px 宽自适应
- 浅暖渐变背景（`#FFF8F0 → #FAF0E6`），浅暖灰边框，圆角 10px
- 含：编号标签(k-id，咖啡棕底白字)、标题、描述、来源

#### 参数卡片（param-card）
- 网格布局，最小 200px 宽自适应
- 浅暖渐变背景，浅暖灰边框，圆角 10px，居中对齐
- 含：标签(12px 灰)、数值(22px 加粗深棕)、进度条(6px 高，圆角)

#### 条形图（bar-chart）
- 水平条形图，每行高 28px
- 标签区(bar-label) 130px 右对齐，轨道区(bar-track) flex 填充
- 填充条(bar-fill) 渐变背景，右对齐显示占比和定位，白色字

#### SVG 决策树（svg-container）
- viewBox `0 0 680 420`，居中，最大宽度 100%
- 根节点/结论节点：深棕渐变矩形（`#3E2723 → #6F4E37`）
- 判断节点：浅棕色块（`#E8D5C0`）+ 焦糖金边框
- 入选分支：绿色半透明底（`#4CAF50 opacity:0.15`）+ 绿色边框
- 落选分支：橙色虚线边框（`stroke-dasharray="4"`）+ 橙色半透明底
- 连接线：焦糖金色 2px

#### 流程图（flow-steps）
- 横向排列，flex 等分
- 每步：白色背景 + 2px 焦糖金边框 + 圆角 10px
- 步骤间用 `→` 箭头连接（绝对定位，焦糖金色 24px）
- 编号圆圈(step-num)：28×28px，咖啡棕底白字

#### 对比表（diff-table）
- 表头灰底（`#EFEBE9`）
- 极致版列(col-extreme)：浅黄底（`#FFF8E1`）
- 合规版列(col-compliant)：浅绿底（`#E8F5E9`）

#### 信息提示框（info-box）
- 左侧 4px 彩色边框，右侧圆角 8px，内边距 12px 16px
- `info-box`（默认）：浅米底 + 咖啡棕边框
- `info-box.warning`：浅黄底 + 橙色边框
- `info-box.danger`：浅红底 + 红色边框
- `info-box.success`：浅绿底 + 绿色边框

#### 挥发梯度色块（gradient-bar）
- 高 40px，圆角 8px，overflow hidden
- 各段 flex 分配宽度，白色加粗文字
- 头香：橙色渐变（`#FFB74D → #FF9800`）
- 体香：棕色渐变（`#8D6E63 → #6F4E37`）
- 基香：深棕渐变（`#5D4037 → #3E2723`）

#### 风险等级标注
- `risk-low`：绿色 `#4CAF50`
- `risk-mid`：橙色 `#FF9800`
- `risk-high`：红色 `#F44336`

### 3.4 响应式
- 最大宽度 1100px，居中
- 移动端（≤768px）：流程图纵向排列，隐藏箭头，表格可横向滚动

## 四、HTML 生成要求

### 4.1 单文件自包含
- 所有 CSS 内联在 `<style>` 标签中
- 不依赖外部资源（无 CDN、无外部字体、无外部图片）
- 可离线打开，便于分享与归档

### 4.2 命名与路径规范
- **文件名（固定短名）**：`report.html`（禁止使用长前缀文件名）
- **输出路径**：`E:\Data\Claude code\flavor-fragrance-expert\deliveries\{香型英文}\{YYYY-MM-DD}_{香型简称}_{场景简称}_{模型slug}\report.html`
- **例**：`deliveries/coffee/2026-07-16_1266甜焦糖_电子雾化_grok-4.5/report.html`
- 同目录须同时有 `overview.md`、`report.md`
- 头部 meta-tags **必须**含模型胶囊：`<span class="meta-tag">🤖 {模型slug}</span>`
- `<title>` 标签：`{配方名称} · 配方报告`
- 详见 `SKILL.md`「交付目录规范」

### 4.3 内容填充规则
- 专家根据实际配方内容填充模板中的占位符 `{{...}}`
- 表格行数根据实际组分数动态生成
- 条形图宽度、进度条宽度根据实际占比计算
- SVG 决策树根据实际特征指纹选择过程绘制，保持节点风格一致
- 不需要的章节（如非雾化场景的第九章）可省略并说明

### 4.4 过程可视化的关键要素

第三章"配方设计过程"是 HTML 报告区别于 MD 文档的核心价值，必须包含：

1. **特征指纹选择决策树（SVG）**：
   - 展示候选特征单体 → 筛选标准 → 最终选择的推导过程
   - 每个选择节点说明"为什么选这个、为什么不选那个"
   - 入选用绿色实线框，落选用橙色虚线框

2. **香韵分路推导流程图（flow-steps）**：
   - 四步推导的可视化：特征路 → 基底路 → 修饰路 → 平衡校验
   - 横向卡片 + 箭头连接，每步展示"识别了什么、选择了哪些分路、为什么"

3. **挥发梯度设计图（gradient-bar）**：
   - 头香/体香/基香的占比可视化色块
   - 每层的关键组分标注

4. **OT值导向用量决策表**：
   - 关键组分的 OT值 → 目标感官贡献 → 最终用量的推导链
   - 警告提示框说明 OT值导向核心原则

### 4.5 记忆透明化的关键要素

- 第二章：列出调用的历史知识（知识卡片 + `[K0XX]` 角标）
- 第十章：列出沉淀的新知识（知识卡片）
- 整个报告中，应用了历史知识的地方用 `<sup>[K0XX]</sup>` 角标标注

## 五、模板使用说明

专家目录下的 `templates/html-report-template.html` 提供了完整的 HTML 骨架。

专家在生成 HTML 报告时：
1. 读取模板文件
2. 根据实际配方内容替换所有 `{{占位符}}`
3. 动态生成表格行、条形图段落、知识卡片、参数卡片
4. 根据实际特征指纹选择过程绘制 SVG 决策树（保持节点风格统一）
5. 根据实际分路推导过程填充流程图卡片
6. 省略不适用的章节并添加说明
7. 输出到本次交付目录：`deliveries/{香型英文}/{YYYY-MM-DD}_{香型简称}_{场景简称}_{模型slug}/report.html`（勿输出到工作区根目录；目录名必含模型）

模板中的占位符格式：`{{占位符名称}}`，如 `{{配方名称}}`、`{{目标场景}}`、`{{组分行循环}}` 等。

### 关键占位符说明

| 占位符 | 说明 |
|--------|------|
| `{{配方图标}}` | 香型对应的 emoji（如 ☕ 🌰 🍓 等） |
| `{{交互序号}}` | 累计交互次数 |
| `{{合规标签类}}` | `tag-ok` / `tag-warn` / `tag-ban` |
| `{{风险类}}` | `low` / `mid` / `high` |
| `{{分路色1}}` / `{{分路色2}}` | 条形图渐变色对 |
| `{{头香flex}}` / `{{体香flex}}` / `{{基香flex}}` | 挥发梯度色块宽度比例 |
| `{{差异色}}` | `#E65100`（降量）/ `#2E7D32`（增量）/ 空（不变） |
| `{{进度百分比}}` / `{{进度色}}` | 参数卡片进度条宽度和颜色 |
